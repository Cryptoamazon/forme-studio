# FORME - AI modeling marketplace slice

A mobile-first, local-only prototype for the core marketplace loop in Justin's 92-point spec.

## Playable locally
- Versioned consent/onboarding demo gates
- Reference image capture with local file checks for type, size, dimensions, and duplicate names
- Synthetic model candidate concepts
- Brand product upload and local preview
- AI Studio generation-job assembly
- Local persistence and clear reset

## Explicitly stubbed
Identity/age/liveness verification, legal agreements, source upload, facial or garment analysis, AI training and generation, provider cost estimates, licenses, payments, payouts, server storage, and collaboration.

No API keys or secrets are used. No uploaded data leaves the browser.
